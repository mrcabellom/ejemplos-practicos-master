# BRI-201 · Informe de ocupación en JSON

- **Abierto por:** equipo del sistema de precios
- **Prioridad:** media
- **Archivos afectados:** `src/pipeline/occupancy.py`, `tests/test_occupancy_format.py` (nuevo)

## Qué se pide

Actualmente, el sistema de precios lee el informe de ocupación como texto
y lo interpreta por columnas, de modo que cualquier cambio de formato lo
rompe.

Se pide una opción `--format json`:

```bash
python -m src.pipeline.occupancy --format json
```

Con ella, el informe debe devolver una lista con un objeto por hotel y
noche:

```json
[{"hotel_id": "MLG", "night": "2026-03-02", "rooms": 7, "capacity": 8, "occupancy": 0.875}]
```

Sin la opción, el informe debe salir exactamente igual que ahora.

## Criterios de aceptación

1. Sin `--format`, la salida no cambia.
2. Con `--format json`, la salida se puede leer con `json.loads` y cada
   elemento tiene las cinco claves.
3. Hay al menos un test nuevo en `tests/test_occupancy_format.py` y
   `python tasks.py test` pasa completo.
