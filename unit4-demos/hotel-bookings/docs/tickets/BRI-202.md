# BRI-202 · Consultar por MCP las filas en cuarentena de un motivo

- **Abierto por:** equipo de datos
- **Prioridad:** baja
- **Archivos afectados:** `mcp_server/server.py`

## Qué se pide

`quarantine_summary` cuenta las filas rechazadas por motivo, pero no
indica cuáles son. Para revisar la cuarentena habría que abrir el
almacén, y `sqlite3` está denegado.

Se pide añadir al servidor MCP `bookings-warehouse` una herramienta
`quarantine_rows` que reciba un `reason_code` y devuelva, como máximo,
`ROW_LIMIT` filas con el `booking_id`, la `business_date` y el `run_id` de
las filas rechazadas por ese motivo.

## Criterios de aceptación

1. `python tasks.py mcp-check` incluye `quarantine_rows` entre las
   herramientas.
2. La herramienta usa la conexión de solo lectura (`mode=ro`) y no acepta
   SQL libre: el motivo se pasa como parámetro.
3. No devuelve el `payload` completo, solo las tres columnas indicadas.
